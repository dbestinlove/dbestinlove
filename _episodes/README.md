# _episodes

Content model for the TikTok series (Stage 2 of `REDESIGN_PLAN.md`). One file
per video: front matter only, body = summary prose. The story chronology,
watch pages, and share cards render from this data instead of hand-edited HTML.

Deliberately **empty at Stage 1** — the first published episode lands with
Stage 2. Keeping the collection directory in place now means the config
surface (`collections:`) and its guardrail test exist before any content does.
